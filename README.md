🔧 Bot "¿Reparo o compro?" — Práctica 4.4-P4

Bot de Telegram construido en Make que recibe la descripción de un aparato con falla y, con inteligencia artificial, recomienda si conviene reparar o reemplazar. También da un costo aproximado y explica el impacto ambiental de desecharlo.
